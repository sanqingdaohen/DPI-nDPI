# 阳瑞任务 —— 专利与论文调研

> **任务主题**：推进 DPI 业务感知方法（聚焦低延时交互底层协议优化 / DPI·NDPI 业务感知 / 传输低延时监控 / 基于行为画像的 NDPI 业务语义感知）
> **两个权利主张（本次调研的落点）**：
> - **主张(1)**：通过 DPI（深度包检测）探测**不同网站信息**的技术能力
> - **主张(2)**：进行**面向用户的包检测记录**并由此进行**用户画像**
> **检索来源**：Patent9 专利在线（中国专利，链接实测可访问）+ arXiv API（论文，含官方摘要）
> **补充说明**：标题"一种基于行为画像的 NDPI 业务语义感知方法及系统"在公开专利库未检索到完全一致记录（可能为在审/内部命名），本调研按两个权利主张提供最接近的公开专利与论文支撑。

## 四、给阳瑞任务的建议

1. **主张(1) 可主张的点**：现有技术（CN110535684A 等）已能"识别网站/业务"，你们的差异化应放在**"加密流量下也能探测网站信息"**（参考 CN111917694A 中兴方案 + 论文 1602.00489 的视频质量识别），或**探测结果的实时/低时延传递**（对应任务里的"传输低延时监控"）。
2. **主张(2) 可主张的点**：现有画像专利多是"识别→存记录→打标签"；论文（2509.23522 / 2605.31277）已经证明**少标注/自监督画像**是趋势——你们的创新点可落在"**画像反哺调度（画像驱动 QoS）**"或"**包检测记录 → 行为画像 → 业务语义**"的闭环上（CN121217842A 是最近的参照系）。
3. **写独创性时**：把上面专利+论文作为"背景技术/对比文件"引用，逐条列出你们的**区别技术特征**，再对应写技术效果（详见《发明专利写作入门与撰写样本.md》第五章模板）。
4. **注意**：直接用"LSTM/Transformer 做流量识别"作创新点会撞车（431+309 条在先专利），模型选型只作载体，创新点放在数据/训练/部署/决策机制。
